# 控制系统的状态空间表达式
## 基本概念
*状态*：控制系统的状态是指系统过去、现在和将来的状况。
*状态变量*：系统的状态变量是指能完全表征系统运动状态的最小一组变量。
	所谓完全表征是指：
	在任何时刻 $t=t_{0}$ ，这组状态变量的值 $x_{1}(t_{0}), x_{2}(t_{0}), \cdots, x_{n}(t_{0})$ 就表示系统在该时刻的状态；
	当 $t \geqslant t_0$ 时的输入 $\pmb{u}(t)$ 给定，且上述初始状态确定时，状态变量能完全确定系统在 $t \geqslant t_0$ 时的行为。
*状态向量*：若一个系统有 n 个彼此独立的状态变量 $x_{1}(t)$ , $x_{2}(t)$ , $\cdots$ , $x_{n}(t)$ ，用它们作为分量所构成的向量 $x(t)$ ，就称为状态向量，即
$$
\boldsymbol {x} (t) = \left[ \begin{array}{c} x _ {1} (t) \\ x _ {2} (t) \\ \vdots \\ x _ {n} (t) \end{array} \right]
$$
*状态空间*：以状态变量 $x_{1}(t), x_{2}(t), \dots, x_{n}(t)$ 为坐标轴构成的 $n$ 维空间称为状态空间。
*状态方程*：描述系统状态变量与输入之间关系的一阶微分方程（组）。
$$
\dot{x}(t) = Ax(t) +Bu(t)
$$
*输出方程*：描述系统输出与状态、输入之间关系的数学表达式。
$$
y(t)=Cx(t)+Du(t)
$$
*状态空间表达式*：状态方程和输出方程组合起来，构成对一个系统动态行为的完整描述，称为系统的状态空间表达式。

## 状态空间表达式的系统框图
在适当的位置上画出积分器，它的数目应等于状态变量数，每个积分器的输出表示对应的状态变量，在其上注明编号，然后根据所给状态方程和输出方程画上加法器和放大器，最后用直线把这些元件连接起来，并用箭头表示出信号的传递方向。

## 状态空间表达式的建立
传递函数中有零点时，采用中间变量法。
$$
\frac{Y(s)}{U(s)}= \frac{b_{n}s^{n}+b_{n-1}s^{n-1}+\dots+b_{1}s+b_{0}}{s^{n}+a_{n-1}s^{n-1}+\dots +a_{1}s+a_{0}}
$$
取中间变量 $Z(s)$：
$$
\left\{\begin{align}
\frac{Z(s)}{U(s)}= \frac{1}{s^{n}+a_{n-1}s^{n-1}+\dots +a_{1}s+a_{0}} \\
\frac{Y(s)}{Z(s)}= b_{n}s^{n}+b_{n-1}s^{n-1}+\dots+b_{1}s+b_{0}
\end{align}\right.
$$
得到
$$
\left\{\begin{align}
z^{(n)}+a_{n-1}z^{(n-1)}+\dots+a_{1}\dot{z}+a_{0}z=u\\
b_{n}z^{(n)}+b_{n-1}z^{(n-1)}+\dots +b_{1}\dot{z}+b_{0}z=y
\end{align}\right.
$$
取 $x_{1}=z,x_{2}=\dot{z},\dots,x_{n}=z^{(n-1)}$，得
状态方程
$$
\dot { x } = \left[ \begin{array} { c c c c c } { { 0 } } & { { 1 } } & { { 0 } } & { { \cdots } } & { { 0 } } \\ { { 0 } } & { { 0 } } & { { 1 } } & { { } } & { { 0 } } \\ { { \vdots } } & { { \vdots } } & { { \vdots } } & { { \ddots } } & { { } } \\ { { 0 } } & { { 0 } } & { { 0 } } & { { \cdots } } & { { 1 } } \\ { { - a _ { 0 } } } & { { - a _ { 1 } } } & { { - a _ { 2 } } } & { { \cdots } } & { { - a _ { n - 1 } } } \end{array} \right] x + \left[ \begin{array} { c } { { 0 } } \\ { { 0 } } \\ { { \vdots } } \\ { { 0 } } \\ { { 1 } } \end{array} \right] u
$$
输出方程
$$
y = \left [\begin{array}&(b_{0}-a_{0}b_{n}) &(b_{1}-a_{1}b_{n})&\dots &(b_{n-1}-a_{n-1}b_{n})\end{array}\right] x + [b_{n}]u
$$
（当 $m<n$ 时，$b_{n}=0$）$y = \left [\begin{array}&b_{0} &b_{1}&\dots &b_{n-1}\end{array}\right] x$。

## 组合系统的状态空间表达式
$N$ 个子系统并联时，组合系统的传递函数矩阵等于 $N$ 个子系统传递函数矩阵之和。
两个子系统串联时,组合系统的传递函数矩阵等于子系统传递函数矩阵的乘积。应注意传递函数矩阵相乘时,先后次序不能颠倒。

## 状态向量的线性变换
给定系统
$$
\dot{x}=Ax+Bu, \quad x(0)=x_{0},\quad y=Cx+Du
$$
取非奇异矩阵（即满秩矩阵）$T$，对 $x$ 作线性变换得 $x = Tz,z=T^{-1}x$。
$$
\left\{ \begin{matrix} 
\dot{z}=\bar{A}z+\bar{B}u \\
y=\bar{C}z+\bar{D}u
\end{matrix}\right.,\qquad
\left\{ \begin{matrix} 
\bar{A}=T^{-1}AT \\   
\bar{B}=T^{-1}B \\
\bar{C}=CT \\
\bar{D}=D
\end{matrix}\right.
$$
显然对系统作线性变换，特征值不变。
### 状态空间表达式变换为约旦规范型
*重数*：特定元素或根在集合、多项式或矩阵中出现的次数。
*代数重数*：特征方程的根的重数，即解特征方程时，某个特征值出现的次数。
*几何重数*：某个特征值对应的线性无关特征向量的个数。
#### 约旦规范型
又称诺尔当标准型，是**矩阵对角化的推广**。并非所有方阵都能对角化，但在复数域内，任何方阵都必定相似于一个结构最简、接近对角矩阵的块状矩阵，即约旦规范型。
##### 定义
设 A 为复数域上的 n 阶方阵，则必存在可逆矩阵 $P$，使得 $J = P^{-1}AP$ 为对角块矩阵，此 $J$ 即为约旦规范型：
$$J = \begin{pmatrix} J_1 & & & 0 \\ & J_2 & & \\ & & \ddots & \\ 0 & & & J_k \end{pmatrix}$$
其中每一个分块 $J_i$ 称为约旦块，它对应某个特征值 $\lambda_i$，其结构为：
$$J_i = \begin{pmatrix} \lambda_i & 1 & 0 & \cdots & 0 \\ 0 & \lambda_i & 1 & \cdots & 0 \\ \vdots & \vdots & \ddots & \ddots & \vdots \\ 0 & 0 & 0 & \lambda_i & 1 \\ 0 & 0 & 0 & 0 & \lambda_i \end{pmatrix}_{m \times m}$$
* 主对角线上的元素全为特征值 $\lambda_i$。
* 上斜对角线（主对角线正上方的一行）的元素全为 1。
* 其余位置的元素全为 0。
##### 特点
1. 唯一性：任一复矩阵的约旦规范型在不计约旦块的排列顺序时是唯一确定的。
2. 重数对应关系：
	* 对应特征值 λ 的所有约旦块的阶数之和，等于该特征值的代数重数。
	* 对应特征值 λ 的约旦块的个数，等于该特征值的几何重数。
3. 极小多项式关系：对应特征值 λ 的最大约旦块的阶数，等于该特征值在矩阵极小多项式中的根的重数。
4. 对角化判据：矩阵可对角化的充要条件是其约旦规范型中的所有约旦块的阶数均为 1 × 1（即几何重数等于代数重数）。

#### 变换阵 T 的求法
##### 系统矩阵 $A$ 具有任意形式
###### 特征值的代数重数＝几何重数
对于系统 $\dot{x}=Ax+Bu$，若矩阵 $A$ 具有 $n$ 个两两相异的特征根 $\lambda_{1},\dots,\lambda_{n}$，则存在线性非奇异变换 $x=Tz$ 将系统化为对角标准型 $\dot{z}=\overline{A}z+\overline{B}u$，其中
$$
\overline{A}=T^{-1}AT = \left[\begin{matrix} \lambda_{1} & & 0\\ & \ddots & \\ 0 & & \lambda_{n} \end{matrix}\right],\quad T=[\begin{matrix}p_{1} & p_{2} &\dots & p_{n}\end{matrix}]
$$
$p_i$ 为 $A$ 的 $n$ 个特征值对应的向量。

状态方程能化成对角标准型的**充要条件**：$n$ 阶系统矩阵 $A$ 有 $n$ 个线性无关的特征向量。
步骤：求特征根和特征向量，如上式用特征向量构造 $T$，并得到 $\overline{A}$，$\overline{B}$，$\overline{C}$。

###### 代数重数>几何重数
设 $A$ 的特征根有 $q$ 个 $\lambda_{1}$ 的重根，其他 $(n-q)$ 个为互异根，则通过变换可以把 $A$ 化为约旦标准型：
$$
\hat{A} =
\left[
\begin{array}{cccc|cccc}
\lambda_1 & 1 & & & & & & \\
 & \lambda_1 & \ddots & & & & & \\
 & & \ddots & 1 & & & & \\
 & & & \lambda_1 & & & & \\
\hline
 & & & & \lambda_{q+1} & & & \\
 & & & & & \ddots & & \\
 & & & & & & \ddots & \\
 & & & & & & & \lambda_n \\
\end{array}
\right]
\left.
\begin{array}{c}
\\
\\
\\
\\
\\
\\
\\
\end{array}
\right\}
\begin{gathered}
q \text{ 维} \\
\\
n-q \text{ 维}
\end{gathered}
$$
变换矩阵 $T=[\begin{array}{cccc|ccc}p_{1} & p_{2} & \dots & p_{q} & p_{q+1} & \dots & p_{n}\end{array}]$，其中 $p_{q+1},\dots,p_{n}$ 为对应 $(n-q)$ 个单根的特征向量，前 $q$ 个 $p$ 为对应 $q$ 个 $\lambda_{1}$ 重根的特征向量。
计算：
$$
\begin{cases}
\lambda_1 P_1 - A P_1 = 0 \\
\lambda_1 P_2 - A P_2 = -P_1 \\
\cdots \\
\lambda_1 P_q - A P_q = -P_{q-1}
\end{cases}
$$
步骤：求特征根和特征向量，如上式用特征向量构造 $T$，并得到 $\overline{A}$，$\overline{B}$，$\overline{C}$。
